# Changelog

All notable changes to this project will be documented in this file.

The format is inspired by [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows Semantic Versioning.

---

## [1.0.0] - 2026-08-25

### Added

- Initial public release of BezelKit.
- Swift Package Manager support.
- `Bezel {}` SwiftUI container API.
- Automatic content scaling and centering.
- Realistic iPad mini device frame rendering.
- Native SwiftUI implementation.
- Rounded display clipping system.
- Titanium chassis rendering.
- Hardware button rendering.
- FaceTime camera rendering.
- Apple Pencil Pro hardware model.
- Apple Pencil charging HUD.
- Apple Pencil connection monitoring.
- Dynamic layout scaling.
- Generic `Content` support through `@ViewBuilder`.
- Package documentation.
- XCTest support.
- Example projects and usage samples.

### Improved

- Refined device frame shadows and highlights.
- Improved bezel rendering accuracy.
- Improved screen clipping performance.
- Improved package structure for Swift Package Manager.

### Technical

- Swift 6 support.
- iOS 17 minimum deployment target.
- Modular package architecture.
- Public API designed for future device profiles.
